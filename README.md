# 方块长安 · Block Xi'an

> Minecraft 方块美学 + 开放城市漫游 + 拍照图鉴收集的西安城市观光小游戏。

不用出门，就能在浏览器里漫游西安：登明城墙、看晨钟暮鼓、走进大雁塔与大唐不夜城、探访兵马俑和华清宫，在昼夜与四季天气中收集自己的长安相册。

项目基于 Vue 3 + Three.js，纯前端运行，无需后端服务。

## 在线预览

**[打开 GitHub Pages，开始漫游方块长安](https://coffey1st.github.io/xian/)**

建议使用最新版 Chrome、Edge 或 Safari 浏览器访问。首次加载 3D 场景可能需要几秒钟。

## 核心内容

- 西安城市地图：碑林、莲湖、新城、雁塔、未央、临潼、长安、灞桥八大区域。
- 24 个景点：钟楼、鼓楼、永宁门、碑林、回民街、大雁塔、大唐不夜城、陕历博、大明宫、兵马俑、华清宫、骊山等。
- 摄影图鉴：第一/第三人称与自拍、长安旧影和盛唐夜色等滤镜、自动识别景点、IndexedDB 相册。
- 城市交通：长安观光巴士、西安地铁快速传送、曲江夜游、骊山索道。
- 文化与美食：泡馍、肉夹馍、凉皮、油泼面；碑林书法、秦俑军阵、盛唐乐舞、丝绸之路。
- 动态世界：昼夜循环、晴/阴/雨/雪、NPC 对话、城市车流、方块化秦岭地形与水系。
- 沉浸声画：程序化长安古韵、风雨环境、脚步/跳跃/拍照/交通音效，以及奔跑速度线、夜景微尘和发现光效。
- PC 与移动端：WASD、触屏摇杆、横屏与全屏适配。

## 快速开始

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

Vite 使用相对路径构建，生产文件输出到 `docs/`，由 GitHub Pages 直接托管。

## 操作

| 按键 | 功能 |
|---|---|
| `W` `A` `S` `D` | 移动 |
| `Shift` / `空格` | 奔跑 / 跳跃 |
| 鼠标 | 旋转视角 |
| `V` | 第一/第三人称 |
| `C` / `F` | 摄影模式 / 快门 |
| `E` | 交互、对话、乘车 |
| `T` | 快进时间 |
| `M` `B` `P` `N` `J` | 地图、背包、相册、图鉴、任务 |

## 项目结构

```text
xian/
├── index.html
├── src/
│   ├── components/       # 菜单、游戏 HUD、地图和图鉴面板
│   └── game/
│       ├── geo.js        # 西安地理投影、道路、水系、交通
│       ├── data.js       # 美食、文化、商店、任务、NPC
│       ├── landmarks/    # 西安景点方块建模
│       └── ...           # 玩家、天气、摄影、城市、物理
└── vite.config.js
```
